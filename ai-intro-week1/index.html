정의

인공지능의 정의

여러 정의가 있지만 공통점은 인간의 지능적 활동을 컴퓨터로 구현한다는 것입니다.

  • 컴퓨터를 사용하여 인간의 지능을 모델링하는 기술
  • 인간과 같이 인식, 사고, 학습 활동 방법 등을 연구하는 분야
  • 컴퓨터를 통해 지능을 구현한 기계 지능(Machine Intelligence)
  • 인간과 유사한 지능이 요구되는 기계 장치를 만드는 기술

목표: 인간의 지능 활동을 컴퓨터에 접목하고, 지능적 원리를 현실 생활에 활용하는 것. 컴퓨터공학뿐 아니라 사회과학, 인문학, 영화, 미술, 음악, 농업, 비즈니스, 광고로 퍼져 있습니다.

왜 배우나

딥러닝 시대에 고전적 AI를 배우는 이유

이유 1

AI의 기초 사고방식 훈련

탐색·추론·제약 문제는 "문제를 공식화하고 해결하는 방법"의 기본 틀. 딥러닝도 결국 탐색 공간을 효율적으로 탐색하는 학습 방법으로 볼 수 있다.

이유 2

"블랙박스" 딥러닝 보완

고전적 AI는 설명 가능성, 명확한 규칙, 증명 가능성을 제공. 예) LLM + 도구 호출/계획 수립, 신경망 + 탐색(알파고의 MCTS).

이유 3

학부생의 인지 발달에 적합

퍼즐, 게임, Wumpus World 같은 작은 문제로 AI 사고방식을 직관적으로 익힌다. 바로 딥러닝을 배우면 "코드 따라 치기"로 끝날 위험.

이유 4

최신 AI를 이해하는 공통 기초

Agentic AI: 목표 → 계획 → 도구 사용 → 피드백
Physical AI: 인식 → 판단 → 계획 → 실제 행동

지능이란

지각 · 판단 · 행동의 순환

지능적이라는 것은 단순히 기능을 수행하는 것이 아니라, 환경을 인식(Perceive)하고, 상황에 맞게 판단(Decide)하며, 목표를 달성하기 위해 적절히 행동(Act)한다는 뜻입니다. 이것이 곧 에이전트 관점입니다.

대상하는 일토론 포인트

두 개의 축

AI 정의의 4가지 접근 방식

무엇으로 평가하는가?

사고(Thought) vs 행동(Behavior)

사고는 내부 추론 과정 자체("어떻게 생각하는가"), 행동은 밖으로 드러나는 행동만("무엇을 하는가") 본다.

무엇이 성공의 기준인가?

인간적(Human) vs 합리적(Rational)

인간을 얼마나 닮았는가, 아니면 주어진 정보 아래 "올바른 것"을 얼마나 잘하는가. 인간은 종종 비합리적이라 두 기준은 일치하지 않는다.

정의

에이전트(Agent)란

감지기(sensor)로 환경을 지각하고, 작동기(actuator)로 환경에 동작을 수행하는 모든 것.

지각 (percept)

특정 순간에 감지기가 받아들이는 입력

지각열 (percept sequence)

에이전트가 지금까지 지각한 모든 것의 전체 이력

동작 (action)

작동기를 통해 환경에 가하는 변화

예감지기 / 지각작동기 / 동작
인간눈, 귀, 피부손, 다리, 성대
로봇카메라, 적외선모터
소프트봇 (Softbot)파일 내용, 네트워크 패킷화면 출력, 파일 쓰기, 패킷 전송
제어기 (Controller)센서 측정값 (설정값과의 차이 이용)제어 입력. 예) 온도조절기
함수 vs 프로그램

에이전트 함수와 에이전트 프로그램

에이전트 함수 (무엇을 하는가)

f : P* → A

가능한 모든 지각열의 집합 P*에서 동작 집합 A로의 사상. 추상적·수학적 서술이고, 원리상 표로 나타낼 수 있다.

에이전트 프로그램 (어떻게 구현하는가)

아키텍처 위에서 에이전트 함수를 구현하는 코드. 매번 현재 지각을 입력받고, 필요한 과거 정보는 내부 상태에 저장한다.

에이전트 = 아키텍처 + 프로그램

표 기반 에이전트(table-driven agent)의 문제

지각이 m종류이고 길이가 t인 지각열은 mᵗ개. 길이 1~T를 모두 저장하면 Σₜ₌₁ᵀ mᵗ개 항목이 필요하다. 지각 4종류, 길이 10만 해도 4¹⁰ = 1,048,576개. 규칙성을 이용하면 훨씬 작은 프로그램으로 같은 행동을 구현할 수 있다.

진공청소기 세계

방 A, B 두 칸과 먼지. 지각은 [위치, 상태], 동작은 Left, Right, Suck, NoOp.

지각열동작
[A, Clean]Right
[A, Dirty]Suck
[B, Clean]Left
[B, Dirty]Suck
[A, Clean], [A, Clean]Right
[A, Clean], [A, Dirty]Suck
…… (표가 무한히 커진다)
 
function REFLEX-VACUUM-AGENT([location, status])
  returns an action
  if status = Dirty then return Suck
  else if location = A then return Right
  else if location = B then return Left

표의 규칙성을 찾으면 몇 줄로 같은 함수를 구현할 수 있습니다. 이 프로그램은 현재 지각만 보고 과거를 기억하지 않습니다. 이것이 좋은 에이전트인지 판단하려면 먼저 합리성의 기준이 필요합니다.

합리성

무엇이 옳은 행동인가

임의의 시점에서 무엇이 합리적인지는 네 가지에 달려 있습니다.

1

성과 측도

성공의 기준. 에이전트가 아니라 설계자가 정하고, 환경 상태의 열(sequence)을 평가한다.

2

사전 지식

환경에 대한 사전 지식. 방 구조를 아는가? 먼지가 다시 생기는가?

3

가능한 동작

할 수 없는 일을 하지 않았다고 비합리적인 것은 아니다.

4

지각열

현재까지의 지각열. 지금까지 본 것에 근거해서만 판단할 수 있다.

합리적 에이전트의 정의

가능한 모든 지각열에 대해, 합리적 에이전트는 그 지각열과 내장된 지식이 제공하는 증거를 바탕으로 성과 측도의 기대치를 최대화할 것으로 예상되는 행동을 선택한다.

a* = argmaxa∈A E[ M | h, K, a ]

h: 지각열 · K: 사전 지식 · M: 성과. 기대치 예) 성공 80%에 10점, 실패 20%에 0점이면 기대 성과는 8점.

왜 "기대치"인가: 환경이 불확실하면 같은 행동도 결과가 달라집니다. 합리성은 실제 결과가 아니라 행동 시점에 알 수 있었던 정보로 계산한 기대 성과로 판단합니다. 결과가 나빴다고 선택이 비합리적이었던 것은 아닙니다.

오해와 요구

합리성은 무엇이 아닌가

합리성 ≠ 전지성 (omniscience)

전지한 에이전트는 실제 결과를 미리 안다. 합리적 에이전트는 알 수 있는 정보 안에서 최선을 다할 뿐. 예) 길을 건너다 추락하는 비행기 문에 맞았다면 비합리적인 게 아니라 운이 없었던 것.

합리성 ≠ 완벽함 (perfection)

합리성은 기대 성과를, 완벽함은 실제 성과를 최대화한다. 예) 승률 70%가 최고의 수였다면 져도 합리적 선택.

합리적 에이전트가 해야 하는 일

정보 수집

지각을 바꾸기 위한 행동도 합리적일 수 있다. 예) 길을 건너기 전 좌우 살피기

학습

경험으로 지식과 행동을 개선. 무엇을 배울지는 비용과 기대 이득을 고려

탐험

정보의 장기적 이득이 비용보다 크면 당장 보상이 낮은 행동도 합리적

자율성

설계자의 사전 지식에만 의존하지 않고 자신의 경험으로 보완. 사전 지식은 출발점, 경험이 그것을 넘어선다

예제

진공청소기 에이전트는 합리적인가?

"합리적인가"는 성과 측도와 환경 가정을 정해야만 답할 수 있습니다.

가정

  • 성과 측도: 1,000 단계 동안 매 단계 깨끗한 칸당 1점
  • 방 구조와 시작 위치는 알고, 초기 먼지 분포는 모른다
  • 깨끗한 칸은 계속 깨끗하고, Suck은 현재 칸을 깨끗하게 만든다
  • Left/Right는 벽에 막히지 않는 한 항상 성공한다
  • 지각은 현재 위치와 그 칸의 상태만 알려 준다

이 가정 아래에서는 합리적

더러우면 빨아들이고 아니면 옆 칸으로 가는 단순 규칙이 기대치를 최대화한다. 어떤 에이전트도 이보다 잘할 수 없다.

가정이 바뀌면 비합리적

이동에 벌점이 있으면 두 칸이 깨끗해진 뒤의 왕복은 손해. 두 칸이 깨끗함을 기억해 NoOp을 고를 수 있다. 먼지가 다시 생기면 점검 주기는 발생률·이동 비용·남은 시간에 달려 있다.

성과 측도 설계

행동이 아니라 결과를 잰다

일반 원칙: 에이전트가 어떻게 행동해야 한다고 생각하는지가 아니라, 환경에서 실제로 무엇이 달성되기를 바라는지를 기준으로 정합니다.

나쁜 측도: 행동을 잰다

"8시간 동안 빨아들인 먼지의 양" → 먼지를 다시 쏟을 수 있다면 같은 먼지를 반복 흡입해 점수를 올릴 수 있다.

좋은 측도: 결과를 잰다

"매 시간 단계마다 깨끗한 칸의 수" → 원하는 환경 상태를 직접 표현. 전력 소모나 소음 벌점을 더할 수도 있다.

  • "평균적으로 깨끗한 바닥"과 "가끔 매우 깨끗하지만 자주 지저분한 바닥" 중 무엇이 나은가? 측도는 가치 판단을 담는다.
  • 측도를 잘못 지정하면 유능한 에이전트일수록 더 크게 어긋난다 (1장의 표준 모형 문제, 강화학습의 보상 해킹).
  • 그래서 4판은 진짜 목적을 확실히 모르는 전제 아래 행동하는 이로운 기계를 제안했다.
한 장 요약

2장 요약

에이전트환경을 지각하고 행동하는 모든 것. 에이전트 함수 f: P* → A는 행동을 서술하고, 에이전트 프로그램은 이를 구현한다.
합리성지각열과 사전 지식에 근거해 기대 성과를 최대화하는 행동. 전지성·완벽함과 다르며, 정보 수집도 비용과 이득으로 판단한다.

에이전트 종류단순 반사 → 모형 기반 반사 → 목표 기반 → 효용 기반. 모두 학습으로 확장 가능. 상태는 원자적·분해된·구조적으로 표현한다.

토론 질문

백개먼은 주사위를 쓰는데 왜 "완전 관측 가능"인가? 포커는 왜 아닌가?

예시 답안: 관측 가능성은 현재 상태가 보이는지의 문제이고, 주사위는 전이의 확률성(확률적) 문제입니다. 백개먼은 판 위의 모든 말이 보이므로 완전 관측이지만, 포커는 상대 패가 숨겨져 있어 부분 관측입니다.

시계를 쓰는 체스가 "준동적"인 이유는?

예시 답안: 숙고하는 동안 판(환경)은 변하지 않지만, 시간이 흐르면서 남은 시간과 성과가 달라지기 때문입니다.

영상 분석이 "일화적"이라면, 의료 진단은 왜 "순차적"인가?

예시 답안: 영상 한 장의 분류는 다음 영상 분류에 영향을 주지 않지만, 의료 진단에서는 어떤 검사·처치를 하느냐가 이후 환자 상태와 다음 선택에 영향을 줍니다.

택시 주행에서 감지기를 추가하면 어느 열이 바뀔 수 있는가?

예시 답안: 관측 가능성 열입니다. 감지기가 늘면 보이는 상태가 늘어 부분 관측에서 완전 관측 쪽으로 가까워질 수 있습니다. 다른 차량의 의도 같은 숨은 상태가 남으므로 완전 관측이 되기는 어렵습니다.

에이전트 프로그램의 종류

네 가지 기본 구조 + 학습

공통 골격은 모두 지각 → (내부 처리) → 행동. 아래로 갈수록 더 많은 정보를 쓰고 더 유연하게 행동하지만, 성능 순위는 아닙니다. 행을 눌러 자세히 보세요.

구조현재 지각내부 상태전이·감지기 모형목표효용 함수학습 요소

● 사용   ◐ 어느 구조에든 붙일 수 있음

연결되는 주제: 탐색·계획 → 목표 달성, 논리·상태 추정 → 세계 표현, 의사결정 → 선호와 불확실성, 학습 → 구성 요소 개선.

상태 표현

무엇을 어떻게 적을 것인가

원자적 atomic

상태는 내부 구조가 없는 하나의 이름표. 예) 도시 이름 A, B. 같거나 다를 뿐.

→ 탐색·게임

분해된 factored

변수(속성)와 값의 집합. 예) [location=A, status=Clean, temp=75°F]. 상태 변수를 플루언트(fluent)라 한다.

→ CSP · 명제 논리 · 계획

구조적 structured

객체들과 그 관계로 된 그래프. 예) "트럭이 소를 향해 후진한다". 표현력이 가장 크다.

→ 1차 논리, 지식 표현 (8~10장)

표현력 vs 추론의 어려움: 풍부한 표현은 객체·속성·관계를 간결하게 나타냅니다. 추론 난도는 표현뿐 아니라 문제와 알고리즘에도 달려 있습니다.

전이 모형

상태 → 행동 → 다음 상태

진공청소기 세계의 상태 공간: 위치 2 × 먼지 분포 4 = 8개 상태.

결정론적

T : S × A → S,  s' = T(s, a)

현재 상태 s에서 행동 a를 하면 다음 상태는 s' 하나.

확률적

P(s' | s, a)

다음 상태를 확률 분포로. 행동 실패나 무작위 먼지 발생을 표현. 현재 상태에 미래 예측에 필요한 정보가 담겼다고 가정.

상태가 변하는 원인: 에이전트의 행동(Suck, Left, Right)과 외부 변화.

연습 · 슬라이드 26

기대 성과로 행동 고르기

성공하면 10점, 실패하면 0점. 슬라이더로 조건을 바꿔 보세요.

행동 B가 실패했다. 그 선택은 비합리적이었을까?

아닙니다. 선택 시점의 정보로 B의 기대 성과(9점)가 A(7점)보다 컸으므로 합리적인 선택이었습니다. 합리성은 실제 결과가 아니라 선택 시점의 정보와 평가 기준으로 판단합니다.

B에만 비용 3점이 붙으면?

B의 순 기대 성과는 9 − 3 = 6점으로 A의 7점보다 작아서 A를 선택합니다.

실습 · 슬라이드 27

기억이 행동을 바꾸는 순간

A에서 시작, 두 칸 모두 Dirty. 6단계 동안 행동 직후 깨끗한 칸마다 +1점, 이동마다 −1점. 청소와 NoOp은 비용 없음.

단계단순 반사점수기억 사용점수
기억 사용 에이전트는 어떤 정보를 기억해야 할까?

각 칸을 마지막으로 확인했을 때 깨끗했는지. 두 칸이 모두 깨끗하다는 사실을 알면 이동하지 않고 NoOp을 선택해 이동 벌점을 피합니다.

먼지가 다시 생긴다면 계속 NoOp 해도 될까?

안 됩니다. "4단계 뒤 A칸 재오염"을 켜고 실행해 보세요. 기억 에이전트는 A가 깨끗하다고 믿고 있어서 다시 치우지 않습니다. 점검 간격을 정하려면 먼지 발생률, 이동 비용, 남은 시간, 마지막으로 확인한 시점 같은 정보가 필요합니다.

개념 점검 · 슬라이드 29

이유까지 설명하기

먼저 스스로 답과 근거(가정 또는 반례 한 문장)를 말해 본 뒤 여세요.

1. 일부 상태가 보이지 않으면 합리적 에이전트가 될 수 없는가?

아닙니다. 합리성은 지각열과 사전 지식으로 알 수 있는 범위에서 기대 성과를 최대화하는 것입니다. 부분 관측 환경에서도 과거 지각으로 상태를 추정하며 합리적으로 행동할 수 있습니다 (합리성 ≠ 전지성).

2. 같은 지각에 항상 같은 행동을 하는 에이전트는 학습할 수 없는가?

아닙니다. 에이전트 함수는 현재 지각이 아니라 지각열 전체를 입력으로 받습니다. 학습 요소가 경험으로 규칙을 고치면, 같은 지각이라도 그 이전 이력에 따라 다른 행동이 나올 수 있습니다.

3. 게임 규칙은 알지만 상대 패는 모른다. 기지/미지와 관측 가능성을 구분하자.

규칙(행동의 결과)을 알므로 기지, 상대 패라는 상태 일부가 보이지 않으므로 부분 관측입니다. 두 구분은 서로 독립입니다.

4. 과거 상태를 기억하는 로봇은 반드시 목표 기반 에이전트인가?

아닙니다. 모형 기반 반사 에이전트도 내부 상태로 과거를 기억하지만, 목표 없이 조건-행동 규칙으로 행동을 고릅니다.

5. 성과 측도, 효용, 보상은 누가 무엇을 평가하기 위해 쓰는가?

성과 측도: 설계자가 외부에서 환경 상태의 열(결과)을 평가. 효용: 에이전트가 내부에서 상태의 바람직함을 평가 (성과 측도의 내재화). 보상: 학습 설정에서 단계마다 주어지는 피드백 신호 (MDP·강화학습).

생각해 볼 문제: 스마트폰 음성 비서는 어떤 에이전트인가? PEAS로 서술해 보자.
